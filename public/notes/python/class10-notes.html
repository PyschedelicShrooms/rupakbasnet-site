User-Defined Functions in Python

What is a Function?
A function is a block of organized, reusable code designed to perform a specific task. Functions help reduce repetition and make programs easier to manage and understand.
Advantages of Functions
  • Reuse code multiple times without rewriting it.
  • Reduce code duplication across the program.
  • Improve program readability and structure.
  • Make debugging easier — fix once, fixed everywhere.
  • Support modular programming — dividing a large program into smaller parts.

Graphics in Python using Turtle

Turtle is a Python module used to draw shapes, patterns, and pictures on screen by moving a virtual pen (called a turtle). The center of the screen is at coordinate (0, 0).
Essential Turtle Statements
StatementWhat it does

screen = turtle.Screen()Creates the drawing window
pen = turtle.Turtle()Creates the turtle object (pen)
turtle.done()Keeps window open until closed manually
turtle.mainloop()Keeps window open, waits for user actions

speed(v)—Set drawing speed (0=fastest)

Error Handling in Python

Error handling is the process of detecting and managing errors during program execution using try, except, else, and finally blocks so the program does not stop suddenly.
Types of Errors
✍️
Syntax Error
Rules of Python are broken while writing code. Detected BEFORE the program runs.
⚡
Runtime Error
Occurs DURING execution. Called an Exception. Example: dividing by zero.
🧠
Logical Error
Program runs but gives wrong output. No error message — hardest to find!
Components of Exception Handling
BlockWhen it runsPurpose
tryAlways (first)Contains risky code that might cause an error
exceptOnly if error occursHandles the error — prevents program crash
elseOnly if NO errorRuns when try block succeeds without error
finallyAlways (last)Cleanup code — runs no matter what happens
Common Exception Types
ExceptionCauseExample
ZeroDivisionErrorDividing a number by zero10 / 0
NameErrorVariable/function not definedprint(name)
TypeErrorWrong data type used"5" + 2
ValueErrorWrong value for correct typeint("abc")
IndexErrorInvalid list indexlist1[5] (only 3 items)
FileNotFoundErrorFile does not existopen("data.txt")
