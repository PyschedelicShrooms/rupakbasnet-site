6. Latency: Network Response Delay ⏱️📡

LATENCY
How long a network takes to reply after we send data.
Latency is the time delay between sending a request and receiving a response. It is measured in milliseconds (ms). The lower the latency, the faster the response.

Write in Copy

  • Latency means delay in data communication.
  • It is usually measured in milliseconds (ms).
  • Low latency means quick response.
  • High latency means slow response or lag.
  • 5G has very low latency, so it is useful for online games, video calls, self-driving cars, remote surgery, IoT and smart city systems.

Teacher Explanation Notes

Easy classroom example: Ask one student a question. If the student replies after 5 seconds, that waiting time is like latency. In a network, latency is the waiting time between sending data and getting a response.

Important difference: Speed means how much data can travel per second. Latency means how quickly the first response comes back. A network can be fast but still feel slow if latency is high.

7. Data Packets 📦

Data packets are small units of data that are transmitted over a network. Large files are broken into smaller packets before being sent.

Write in Copy

  • Large data is divided into small packets.
  • Each packet contains part of the data.
  • Packets also contain source, destination and sequence number.
  • Packets travel through the network and reassemble at the destination.

Teacher Analogy

A big book can be sent as many pages in separate envelopes. The receiver arranges pages again using page numbers.

10. Frequency 〰️

Frequency is the number of times a signal oscillates or completes cycles per second. It is measured in Hertz (Hz).

Write in Copy

  • Frequency means cycles per second.
  • One hertz means one cycle per second.
  • If a signal completes two cycles in one second, its frequency is 2 Hz.
  • Higher frequency means more cycles in one second.

Write in Copy

  • Frequency means the number of cycles or waves per second.
  • The unit of frequency is Hertz (Hz). 1 Hz means 1 cycle per second.
  • Radio, TV, Wi‑Fi, Bluetooth, mobile networks and satellites use frequency to send signals.
  • Different devices use different frequency channels so their signals do not mix.
  • Higher frequency has more cycles per second and usually shorter wavelength.

Teacher Explanation

Ask students to imagine a classroom where everyone speaks at the same pitch and same time: it becomes confusing. Communication systems use different frequencies like separate speaking channels, so radio, Wi‑Fi and mobile signals can travel without mixing.

13. Communication Modes: Direction of Data Flow ↔️

HOW DO DEVICES TALK?

Communication mode tells us whether data moves one way, both ways by turn, or both ways at the same time.

Communication mode is the direction and timing of data transmission between two devices.
📺 ➡️ 🏠

Simplex

One direction only.
Receiver cannot reply on the same channel.

🎙️ ↔️ 🎙️

Half Duplex

Both directions, but one at a time.
Take turns like walkie-talkie.

📱 🔄 📱

Full Duplex

Both directions at the same time.
Talk and listen together.

Easy Memory Trick

  • Simplex = one-way road 🚗➡️
  • Half duplex = one narrow bridge: one side goes, then the other side goes 🌉
  • Full duplex = two-lane road: both sides move together 🛣️
