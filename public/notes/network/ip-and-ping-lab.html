2. IP Address

WHAT IS AN IP ADDRESS?

An IP address is a logical address used to identify a device on a network.

🏠 Think of it like a house address. It helps network data know where to go.

TRY IT — Send a Message

The destination IP address helps the network identify where the packet should go.

Private vs Public IP

🏠 PRIVATE NETWORK

Laptop: 192.168.1.10

Phone: 192.168.1.11

Router: 192.168.1.1

Common inside homes, schools and offices.
🌍 INTERNET

Public example: 222.32.101.111

A public IP can be used when communicating over the Internet.
Laptop 192.168.1.10 → Router → Public connection → Internet → Website Server

Static IP

School Server: 192.168.1.20

Static means the address stays manually configured until it is changed.

Dynamic IP (DHCP)

DHCP can automatically give network settings to a device.

Current laptop IP: 192.168.1.25

Reconnect to see another example dynamic address.
REMEMBER: IP ADDRESS = LOGICAL NETWORK ADDRESS

4. IPv6

WHY IPv6?

More phones, laptops, watches, TVs, cars, cameras and other devices need addresses. IPv6 provides a much larger address space.

IPv4

📱 💻 ⌚ 📺 🚗 🎮

32 bits

Smaller address space.

IPv6

📱 💻 ⌚ 📺 🚗 🎮 📷 🏠

128 bits

Extremely large address space.

IPv6 Format

IPv6 uses hexadecimal characters: 0–9 and A–F, separated by colons.

IPv6 Zero Compression

2001:0db8:0000:0000:0000:ff00:0042:8329
IPv6 allows some zeros to be shortened so the address is easier to write.

IPv4

Version 4

32 bits

Decimal numbers + dots

192.168.1.1

Smaller address space

IPv6

Version 6

128 bits

Hexadecimal groups + colons

2001:db8::42:8329

Much larger address space

REMEMBER: IPv6 = 128 BITS + HEXADECIMAL GROUPS + COLONS
5. Ping

PING LAB

Ping checks whether another network device can be reached and measures how long a reply takes.

Computer → Network → Destination
Lower ping usually means the reply comes back faster. Network traffic and routing can also affect response time.
C:\> Ready for ping...
REMEMBER: PING = CHECK REACHABILITY + RESPONSE TIME
6. MAC Address

MAC ADDRESS

A MAC address is an identifier associated with a network interface.

View Network Identity

💻
Tap the button to reveal the device's IP and MAC address.

IP Address vs MAC Address

IP ADDRESS

192.168.1.10

Helps identify where data should be delivered logically on a network.

Can change depending on network settings.

MAC ADDRESS

48-3F-0A-91-00-BC

Identifies a network interface on the local network.

Often described as a physical or hardware address in school-level networking.

SEE IT — Local Network Delivery

IP helps identify the logical destination. MAC helps local delivery between network interfaces.
REMEMBER: MAC = NETWORK INTERFACE IDENTIFIER
7. Internet, Intranet and Extranet

Who can access what?

🌍 INTERNET

A worldwide network of connected networks.

Example: Visiting a public website.

🏫 INTRANET

A private network used inside an organization.

Example: Teachers viewing internal school notices.

🤝 EXTRANET

Controlled private access for selected people outside an organization.

Example: A parent viewing a child's attendance.
