Part H — Visual Summary

CLIENT–SERVER

Central server provides services to clients.

Example: Browser → Web Server → Browser

Best suited for schools, businesses, banks, websites, and large organizations.

PEER-TO-PEER

Devices communicate and share resources directly.

Example: Peer A ↔ Peer B

Best suited for small networks, direct file sharing, and distributed file-sharing systems.

CLIENT–SERVER = CENTRAL SERVER
